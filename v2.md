OpenCluely v1 demonstrated functional demand for an AI-powered interview and assessment copilot, but accumulated critical structural failures across security, reliability, audio/video ingestion, and latency:

```
| - Native OS dropdown capture leaks | - Missing conversational turn VAD | - Single DSA skill limit  |
+------------------------------------+-----------------------------------+---------------------------+
```

### Direct Root-Cause Audit from PRs, Issues & Discussions
1. **Stealth Breakdown (Issues #68, #66, #52, #46, #5, #38; PRs #67, #53, #51)**:
   - Proctoring engines (Safe Exam Browser, HirePro, Mettl, Proctorio, Mercer) inspect Win32 `EnumWindows`, `GetClassName`, and style flags. Electron windows register under `Chrome_WidgetWin_1` / `ChromeNativeWindow` with `WS_EX_LAYERED` (transparency) and `WS_EX_TOPMOST`.
   - Native HTML `<select>` dropdowns create unshielded OS window controls that bypass `setContentProtection(true)`, rendering directly into Zoom/Teams/Meet captures.
   - Screen capture protection (`NSWindowSharingNone` / `WDA_EXCLUDEFROMCAPTURE`) silently failed on Linux (Wayland/X11) and suffered regressions on macOS Sonoma 14+.
   - Unhandled focus requests (`mainWindow.focus()`) fire `WM_KILLFOCUS` and `WM_ACTIVATE` events into proctoring browser tabs, causing instant "tab switch" / "focus lost" disqualifications.
2. **Audio Pipeline Fragility (Issues #55, #33, #28, #26, #25, #21, #20; PRs #73, #63, #29, #17)**:
   - External Python worker (`scripts/whisper_worker.py`) required host Python 3.10+, PyTorch, and `openai-whisper`, failing silently on missing host dependencies (`sox`, `rec`, `arecord`, `ffmpeg`).
   - 2,000+ lines of Node.js browser polyfills for Azure SDK created unhandled child process panics that crashed the entire app on hotkey execution.
   - Total lack of interviewer system audio loopback capture: only candidate mic audio was transcribed, rendering conversational interview help useless until partial PR #73.
   - Absence of acoustic turn-detection: mid-sentence pauses broke continuous questions into multiple premature fragments, triggering rate limits and hallucinated answers.
3. **Vision & OCR Latency (Issues #40, #58; PRs #73, #51)**:
   - `desktopCapturer` took unoptimized full-display snapshots, base64-encoded multi-megabyte PNGs, and pushed them across network boundaries with 4-8 second turnaround times.
   - Missing native display DPI scaling caused cropped snips to misalign on Windows 125%/150% scaling.
4. **AI & Provider Brittleness (Issues #71, #64, #47, #39, #36, #34; PRs #54, #44, #43, #37, #16)**:
   - Hardcoded dependency on Google Gemini; quota exhaustion resulted in static, confusing fallback text: *"This appears to be a data structures and algorithms problem..."*.
   - Streaming LLM chunk events were broadcast over IPC to *all* windows (including hidden ones), choking Electron's event loop and freezing UI rendering.
   - Response window stayed stranded on screen when the master toggle `Ctrl+Shift+V` was pressed (Issue #71).
   - DeepSeek/Gemini/OpenAI chain-of-thought `<think>` blocks streamed into UI answer cards, confusing users during live interviews.

## 6. Stealth & Anti-Detection Specification (Zero-Fingerprint Engine)

Assessment platforms (Safe Exam Browser, HirePro, HackerRank, Mettl, Proctorio) execute multi-layered detection. v2 eliminates every exposed attack surface:

```
       Proctoring Detection Vector                       v2 Mitigation Implementation
+----------------------------------------+-----------------------------------------------------------+
| 1. Win32 EnumWindows Enumeration       | Register dynamic benign class: "Shell_TrayWnd_Worker"     |
| 2. Window Transparency Hook            | Hardware opaque backbuffer + Alpha blend shader           |
| 3. Focus / Active Window Monitoring    | WS_EX_NOACTIVATE: Windows never take OS keyboard focus    |
| 4. Screen-Share / Recording Inspection | WDA_EXCLUDEFROMCAPTURE / NSWindowSharingNone              |
| 5. Process Table Enumeration           | Dynamic PE Header Masking & Benign Executable Renaming    |
| 6. Global Shortcut Hook Interception   | Low-level asynchronous WH_KEYBOARD_LL hook listener       |
+----------------------------------------+-----------------------------------------------------------+
```

### 6.1. OS-Level Invisibility Implementation

#### Windows (Win32 Core):
```rust
// Windows Display Exclusion & Anti-Focus Capture
pub unsafe fn harden_stealth_window(hwnd: HWND, transparent_mode: bool) {
    // 1. Exclude window from all DWM screen captures, Zoom, Teams, Meet, and OBS
    // WDA_EXCLUDEFROMCAPTURE = 0x00000011 (Windows 10 2004+ and Windows 11)
    SetWindowDisplayAffinity(hwnd, 0x00000011);

    // 2. Set Window Extended Styles
    let mut ex_style = GetWindowLongPtrW(hwnd, GWL_EXSTYLE) as u32;
    
    // WS_EX_NOACTIVATE prevents window from ever stealing focus on click
    ex_style |= WS_EX_NOACTIVATE;
    
    // WS_EX_TOOLWINDOW hides it from Alt-Tab and Taskbar
    ex_style |= WS_EX_TOOLWINDOW;
    ex_style &= !WS_EX_APPWINDOW;

    if transparent_mode {
        // Use layered window only when transparency is strictly requested
        ex_style |= WS_EX_LAYERED;
    } else {
        // Strip layered flag to defeat proctoring heuristics checking for WS_EX_LAYERED overlays
        ex_style &= !WS_EX_LAYERED;
    }

    SetWindowLongPtrW(hwnd, GWL_EXSTYLE, ex_style as isize);

    // 3. Spoof Window Class Name via Win32 RegisterClassExW
    // Replaces default Chrome_WidgetWin_1 with innocuous OS names (e.g., "EdgeUiWorker_Host")
}
```

#### macOS (Cocoa Core):
```objc
// macOS Screen Invisibility and Non-Activating Level Enforcement
- (void)configureStealthWindow:(NSWindow *)window {
    // 1. Completely exclude from ScreenCaptureKit, Zoom, and AirPlay
    [window setSharingType:NSWindowSharingNone];

    // 2. Float above fullscreen windows without stealing focus or Dock presence
    [window setLevel:NSScreenSaverWindowLevel];
    [window setCollectionBehavior:(NSWindowCollectionBehaviorCanJoinAllSpaces |
                                   NSWindowCollectionBehaviorFullScreenAuxiliary |
                                   NSWindowCollectionBehaviorStationary |
                                   NSWindowCollectionBehaviorIgnoresCycle)];

    // 3. Ignore mouse clicks on demand & prevent key window status
    [window setIgnoresMouseEvents:NO];
    [window setCanHide:NO];
}
```

#### Linux (Wayland / X11 Strategy):
On Linux, `setContentProtection` does not exist at the display compositor level. v2 introduces two robust countermeasures:
1. **Virtual Display Sink / Second XScreen**: Spawns overlay on a decoupled X11 display sink (`:99` or secondary virtual DRM output) that is not included in the single-window/monitor share.
2. **KMS/DRM Hardware Overlay Plane**: On supported Wayland compositors, routes UI to a private hardware underlay/overlay plane not exposed to PipeWire screencast portals.

### 6.2. Anti-Focus Stealing Protocol
- The overlay window **NEVER** becomes the Foreground Window (`GetForegroundWindow` always returns the interview IDE/browser).
- All mouse clicks on the overlay UI are intercepted via raw input (`WM_NCHITTEST` returning `HTCLIENT` without `WM_ACTIVATE`).
- Typing into the overlay is handled through an off-screen virtual input buffer or global input listener without shifting OS focus.

### 6.3. Native Widget Leak Elimination
- All HTML `<select>`, `<dialog>`, and context menu elements are prohibited.
- Dropdowns, tooltips, and modal views are rendered strictly using custom DOM/SVG/Canvas elements styled within the application framebuffer so no child OS window handles (`HWND` / `NSView`) are registered with the window manager.

### 6.4. Panic Killswitch & Chameleon Masking
- **Panic Hotkey** (`Ctrl+Alt+Q` or rapid 3-click gesture):
  - In `0ms`: Hides all overlay buffers, zeroes memory pages containing transcript history, and sets display affinity to normal.
- **Chameleon Mode**:
  - Transforms the overlay in 50ms into a fake benign utility (system clock, native terminal with fake git logs, or calculator).

```
[ CANDIDATE AUDIO ] (Microphone)                                    v
       |---> Native MiniAudio / PortAudio Input ----> [ Channel B: Microphone Buffer ]

                                                                    |
```

### 7.1. Hardware-Direct Audio Capture (No Virtual Cables)
- **Windows**: Direct WASAPI loopback (`AUDCLNT_STREAMFLAGS_LOOPBACK`) on the default render device. Captures crystal-clear interviewer voice directly from Zoom/Teams/Browser audio without requiring VB-Cable.
- **macOS**: CoreAudio HAL Audio Object TAP (`AudioHardwareCreateProcessTap` on macOS 14.2+) or native ScreenCaptureKit Audio Stream.
- **Linux**: PulseAudio/PipeWire monitor source stream.

### 7.2. Zero-Dependency Embedded STT Engine
- **Embedded Engine**: **`whisper.cpp`** compiled as a native shared library or statically linked Rust crate (`whisper-rs`).
- **Models**: Quantized `ggml-small.bin` (Q5_0, ~140MB) and `ggml-base.bin` (Q5_1, ~65MB).
- **Hardware Acceleration**:
  - macOS: Apple Silicon Metal Performance Shaders (MPS) via Accelerate framework.
  - Windows: DirectML / CUDA / AVX-512 vector extensions.
  - Latency: **< 120ms** per transcribed speech chunk.

### 7.3. Conversational Turn Detector & Coalescing Engine
Prevents premature submissions when the interviewer pauses to think:
- Active speech frames detected via Silero VAD (512-sample frame size, 16kHz PCM).
- Trailing silence threshold defaults to `2400ms` for Interviewer Channel (Interviewer mode) and `1200ms` for Candidate Channel.
- Drain Barrier: No question is committed to the LLM until the audio stream has settled and transcribed completely.
- Hallucination Guard: Filters known Whisper phantom outputs on silence (`"Thank you"`, `"Subtitles by..."`, `"Bye!"`).

### 9.2. Visible-Answer Stream Sanitizer
DeepSeek R1, Gemini 2.0 Flash Thinking, and modern models emit reasoning blocks that must never be shown during an interview. v2 filters tokens across chunk boundaries using a state-machine tokenizer:

```rust
pub struct StreamSanitizer {
    in_reasoning: bool,
    buffer: String,
}

impl StreamSanitizer {
    pub fn process_chunk(&mut self, chunk: &str) -> Option<String> {
        self.buffer.push_str(chunk);
        
        // Strip <think> ... </think>, <reasoning> ... </reasoning>, etc.
        while let Some(start) = self.find_tag_start(&self.buffer) {
            if let Some(end) = self.find_tag_end(&self.buffer[start..]) {
                self.buffer.drain(start..(start + end));
            } else {
                // Partial tag opened; wait for closing chunk
                return None;
            }
        }
        
        let output = self.buffer.clone();
        self.buffer.clear();
        Some(output)
    }
}
```

### 14.1. OS-Friendly Native CLI Install Scripts

#### Windows Native PowerShell (`install.ps1`):

```powershell
# Run in Windows PowerShell:
irm https://opencluely.techycsr.dev/install.ps1 | iex
```
*Script Execution Flow*:
1. Queries GitHub API for the latest `OpenCluely-Setup.exe` release asset.
2. Downloads executable to `$env:TEMP\OpenCluely-Setup.exe` via BITS/WebClient.
3. Silently launches the installer and spawns the app directly.

#### macOS Native Shell (`install.sh`):
Runs in macOS Terminal (Zsh/Bash) and completely bypasses Gatekeeper quarantine:
```bash
# Run in macOS Terminal:
curl -fsSL https://opencluely.techycsr.dev/install.sh | bash
```
*Script Execution Flow*:
1. Downloads the latest universal DMG/ZIP for Apple Silicon & Intel.
2. Extracts directly to `/Applications/OpenCluely.app`.
3. Runs `xattr -cr /Applications/OpenCluely.app` (removes Apple quarantine attribute).
4. Launches OpenCluely immediately with **zero Gatekeeper warning dialogues**.

### 14.2. macOS DMG Gatekeeper Bypass Without Apple Developer ID ($99/yr)

In v1, unsigned builds triggered Gatekeeper's *"OpenCluely is damaged and should be moved to the Trash"* because the binary had no code signature. In v2:
1. **Automated Ad-Hoc Signing (`codesign -s -`)**: Tauri's build pipeline applies a free native ad-hoc signature to the `.app` bundle. This eliminates the "damaged" warning entirely.
2. **First-Time Launch Experience**:
   - **Method A (Right-Click Open)**: Right-click `OpenCluely.app` in `/Applications` ➔ Click **Open** ➔ Click **Open** on the confirmation prompt.
   - **Method B (System Settings)**: Open **System Settings ➔ Privacy & Security** ➔ Click **[Open Anyway]** under the Security section.
   - macOS stores this exemption permanently in its local security database; the prompt never appears again.
3. **Website UX**: The download page displays a clean 2-step graphic showing this 3-second action.
